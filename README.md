# Bot បញ្ជីម្ហូប (Telegram Menu Bot)

កត់ត្រាម្ហូបតាមប្រភេទ (សម្ល, ឆា, ចៀន/អាំង ...) ហើយ bot ណែនាំម្ហូបល្ងាចរៀងរាល់ថ្ងៃ: **មួយមុខក្នុងមួយប្រភេទ**។

## 1. បង្កើត bot
1. ក្នុង Telegram បើក **@BotFather** → `/newbot` → ចម្លង **token**។
2. **សម្រាប់ក្រុម:** ក្នុង BotFather វាយ `/setprivacy` → ជ្រើស bot → **Disable** រួចដក bot ចេញ ហើយបញ្ចូលទៅក្រុមវិញ។ (បើមិនធ្វើទេ bot មើលមិនឃើញការចុចប៊ូតុងក្នុងក្រុម។)
3. (ជម្រើស) ក្នុង BotFather វាយ `/setcommands` រួចបិទភ្ជាប់:
   ```
   suggest - ម្ហូបណែនាំថ្ងៃនេះ
   add - បន្ថែមម្ហូប
   list - បញ្ជីម្ហូប
   settings - ការកំណត់
   time - ម៉ោងណែនាំ
   addcat - បន្ថែមប្រភេទម្ហូប
   sample - បន្ថែមម្ហូបគំរូ
   help - របៀបប្រើ
   ```

## 2. របៀបប្រើ
វាយ `/start` នោះប៊ូតុងនឹងបង្ហាញ:
```
[ 🎲 ណែនាំម្ហូប ] [ ➕ បន្ថែមម្ហូប ]
[ 📋 បញ្ជីម្ហូប ]  [ ⚙️ ការកំណត់ ]
```

- **➕ បន្ថែមម្ហូប**: ជ្រើសប្រភេទ រួចវាយឈ្មោះម្ហូប។ បើចង់បញ្ចូលច្រើនមុខក្នុងពេលតែមួយ សរសេរមួយបន្ទាត់មួយមុខ ឬដាក់សញ្ញាក្បៀស: `សម្លកកូរ, សម្លម្ជូរ, ស្ងោរជ្រក់`
- **🎲 ណែនាំម្ហូប**: ម្ហូបសម្រាប់ល្ងាចនេះ។ ចុច 🔄 ដើម្បីប្តូរម្ហូបមួយមុខ ឬ 🔄 ប្តូរទាំងអស់ ហើយចុច ✅ ពេលយល់ព្រម។
- **📋 បញ្ជីម្ហូប**: មើលម្ហូបទាំងអស់តាមប្រភេទ។ ចុចលើប្រភេទណាមួយ ដើម្បីលុប (🗑) ឬបន្ថែមម្ហូប។
- **⚙️ ការកំណត់**: ✅/⬜ ជ្រើសប្រភេទណាដែលត្រូវដាក់ក្នុងការណែនាំរាល់ល្ងាច ហើយ 🗑 សម្រាប់លុបប្រភេទ។
- `/time 17:00`: ប្តូរម៉ោងណែនាំ។ `/time off` សម្រាប់បិទ។
- `/addcat 🐟 ត្រី`: បន្ថែមប្រភេទថ្មី។
- `/sample`: បន្ថែមម្ហូបខ្មែរគំរូ ២១ មុខ សម្រាប់ចាប់ផ្តើម។

ប្រភេទដែលមានស្រាប់: 🍲 សម្ល ✅, 🥘 ឆា ✅, 🍗 ចៀន/អាំង ✅, 🥗 ញាំ/បន្លែ ⬜, 🍮 បង្អែម ⬜

**ការណែនាំស្វ័យប្រវត្តិ:** រាល់ថ្ងៃម៉ោង 17:00 (អាចប្តូរបាន) bot ផ្ញើម្ហូបណែនាំទៅក្រុម។ Bot ព្យាយាមមិនណែនាំម្ហូបដដែល ក្នុងរយៈពេល ៥ ថ្ងៃ។ ប្រសិនបើក្រុមមិនទាន់មានម្ហូបទេ bot មិនផ្ញើអ្វីទេ។

**ក្រុម:** ក្រុមនីមួយៗមានបញ្ជីម្ហូប ប្រភេទ និងម៉ោងរបស់ខ្លួនដាច់ពីគ្នា។ Chat ផ្ទាល់ជាមួយ bot គឺជាបញ្ជីផ្ទាល់ខ្លួន។

## 3. ដំណើរការលើកុំព្យូទ័រ
```bash
pip install -r requirements.txt
# Windows PowerShell
$env:BOT_TOKEN="123456:ABC..."
python bot.py
```
ទិន្នន័យរក្សាទុកក្នុងឯកសារ `menu.db`។

## 4. ដាក់ online
ធ្វើដូច README របស់ payment-bot ដែរ (Render + Neon + cron-job.org) ដោយមានភាពខុសគ្នាដូចខាងក្រោម:
- **Neon:** អាចប្រើ database តែមួយជាមួយ payment-bot បាន ព្រោះតារាងទាំងអស់មានឈ្មោះចាប់ផ្តើមដោយ `menu_` ដូច្នេះមិនជាន់គ្នាទេ។
- **cron-job.org:** ត្រូវការតែ job "Keep awake" (`https://<app>/` រៀងរាល់ ១០ នាទី) ប៉ុណ្ណោះ។ (ជម្រើស) អាចបន្ថែម `https://<app>/cron/suggest?key=CRON_SECRET` រៀងរាល់ ៥ នាទីផងដែរ។
- ⚠️ **Render Free** ផ្តល់ 750 ម៉ោង/ខែ ដែលគ្រាន់សម្រាប់ app **តែមួយ** ដែលបើករហូត។ ប្រសិនបើ payment-bot កំពុងដំណើរការលើ Render រួចហើយ ត្រូវប្រើគណនី Render ទីពីរ សម្រាប់ bot នេះ។

## ការកំណត់ (Environment variables)
| Variable | Default | អត្ថន័យ |
|---|---|---|
| `BOT_TOKEN` | (ត្រូវតែមាន) | Token ពី BotFather |
| `DATABASE_URL` | (ទទេ = SQLite) | PostgreSQL connection string |
| `DB_PATH` | `menu.db` | ឯកសារ SQLite |
| `BOT_TZ` | `Asia/Phnom_Penh` | Time zone |
| `SUGGEST_TIME` | `17:00` | ម៉ោងណែនាំសម្រាប់ក្រុមថ្មី |
| `REPEAT_DAYS` | `5` | មិនណែនាំម្ហូបដដែលក្នុងរយៈពេលប៉ុន្មានថ្ងៃ |
| `CRON_SECRET` | (ទទេ = បិទ) | ពាក្យសម្ងាត់សម្រាប់ `/cron/suggest` |
| `WEBHOOK_URL` | (auto លើ Render) | អាសយដ្ឋានសាធារណៈ |
| `PROXY` | (ទទេ) | ឧ. `socks5://127.0.0.1:1080` |
